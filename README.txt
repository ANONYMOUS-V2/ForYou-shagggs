PROJECT SHAGGGGS — Website package

HOW TO PREVIEW
1. Extract this ZIP.
2. Keep index.html and the assets folder together.
3. Open index.html in a modern browser.

HOW TO PUBLISH FOR FREE
- Netlify Drop: visit https://app.netlify.com/drop and drag the extracted project folder (or a ZIP if accepted by the current interface).
- GitHub Pages: create a repository, upload index.html and the assets folder, then enable Pages in repository settings.

IMPORTANT
- The letter codes are STAR, MOON, ROSE, CLOUD, KIND, HEART, HOME (one per letter, in order).
- These are playful front-end locks, not real security. Anyone with access to the site files can inspect them.
- Visited rooms are saved in localStorage on the visitor's browser/device.
- The final letter is a gentle starter draft. Edit the text in index.html if you want it to sound more like your own words.
- Only publish/share the photo if you have her permission or are confident she would be comfortable with it. The website is meant as a private, respectful gift.
